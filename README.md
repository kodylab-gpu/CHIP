# Chip AI Atlas

A black-and-white, static AI tool directory with 107 curated links, logo favicons, responsive layout and 25+ interactive capabilities.

## Deploy to Vercel

1. Upload **the files inside this folder** to the root of a GitHub repository.
2. In Vercel choose **Add New → Project → Import repository**.
3. Framework preset: **Other**. Root Directory: `./`. Build command: leave empty. Output directory: leave empty (default static root).
4. Deploy. No API keys, environment variables, Python, or FastAPI required.

## Main features

1. Full-text search 2. Category filtering 3. Category chips 4. Favorites 5. Recent opens 6. Compare selection (up to 4) 7. Editor picks 8. Hidden tools 9. Random discovery 10. A–Z sort 11. Z–A sort 12. Category sort 13. Grid/list toggle 14. Compact mode 15. Light/dark inversion 16. Tool details 17. Personal notes 18. Copy individual link 19. Copy favorite links 20. Export CSV 21. Export JSON backup 22. Import JSON backup 23. Restore hidden tools 24. Clear recent 25. Clear comparison 26. Share site 27. Keyboard shortcuts 28. Responsive navigation 29. Search reset 30. Progressive load more 31. Visited indicators 32. Suggest a tool via mail client.

Logos use Google's public favicon endpoint and need internet access. This directory is not affiliated with listed brands. The site doesn't provide AI chat; it links to third-party AI tools. Links, branding, access and prices can change.
